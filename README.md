# MacClean Uninstaller

Нативный прототип деинсталлятора для macOS на SwiftUI. Целевая архитектура: Intel x86_64. Минимальная версия macOS: 14.0 (Sonoma).

## Возможности прототипа

- Список приложений из `/Applications` и `~/Applications`.
- Поиск по имени и Bundle Identifier.
- Приблизительный подсчёт размера приложения.
- Поиск возможных пользовательских остатков в `~/Library/Caches`, `Preferences`, `Application Support`, `Logs`, `Containers` и `Saved Application State`.
- Перемещение выбранных элементов в Корзину с подтверждением.
- Русский интерфейс.

## Ограничения и безопасность

Это ранний прототип, не сертифицированный деинсталлятор. Совпадение имени или Bundle Identifier не доказывает, что файл принадлежит приложению. Перед удалением внимательно проверьте полный путь. Общие данные и настройки могут использоваться другими программами.

Приложение намеренно не сканирует системные каталоги и не пытается удалять системные приложения. Некоторые операции могут быть запрещены macOS или требовать прав, которыми приложение не обладает. Ничего не удаляется без явного подтверждения; выбранные элементы перемещаются в Корзину, если macOS разрешает это.

## Сборка на Intel Mac

1. Установите Xcode из Mac App Store или с сайта Apple.
2. Откройте `MacCleanUninstaller.xcodeproj`.
3. Выберите схему `MacCleanUninstaller` и ваш Mac как destination.
4. В настройках проекта проверьте `macOS Deployment Target = 14.0` и `Architectures = Standard Architectures`.
5. Нажмите `Product → Build` (⌘B), затем `Product → Run` (⌘R).

Проект настроен на стандартные архитектуры Xcode; на Intel Mac должен собраться Intel-вариант. Приложение не требует Apple Silicon.

## Структура

- `App/MacCleanUninstallerApp.swift` — точка входа.
- `App/Models/` — модели приложения и найденных файлов.
- `App/Services/` — сканирование и безопасное перемещение в Корзину.
- `App/Views/ContentView.swift` — интерфейс.

## Статус

Начальный прототип. Перед повседневным использованием необходимы тестирование на копиях данных, проверка корректности размеров каталогов, обработка ошибок доступа и более точная идентификация связанных файлов.
